# ファイルとデータの基礎 — 教材ドラフト

PC基礎で学んだ「保存」の話を、実際に資料を扱い、AIへ渡して検証できる段階につなげます。8レッスン・24到達項目・72問です。初回は1レッスン3問、再確認は誤答した項目から別問題を出題します。

|順番|内容|実践で確かめること|
|---|---|---|
|1|ファイルを扱う言葉|中身・名前・形式・保存場所を分ける|
|2|保存場所|保存したものを目的の場所から開き直す|
|3|形式と変換|編集用と配布用の違いを説明する|
|4|コピー・保存・版|原本を残し、作業用だけ変更する|
|5|表とCSV|行・列・単位・識別子を定義する|
|6|画像・PDF・OCR|見える、検索できる、正しく抽出できるを分ける|
|7|同期・バックアップ・共有|変更の伝わり方、戻し方、権限を整理する|
|8|AIへの資料準備|目的から入力資料を選び、読み取りと出力を照合する|

時間は固定しません。必要な箇所を読み直し、実践メモを残せます。実践メモと最後の資料準備課題は自己説明・講師確認用で、自動採点するものではありません。

解説の正本は `lessons/`、問題の正本は `assessments/`、コース構成と最終課題は `course.json` です。初期作成スクリプトは編集済みのJSONを上書きしません。

## 内容確認の観点

- 用語を未説明のまま操作指示に使っていないか。
- 誤答の選択肢が実際に起きる誤解を表しているか。
- 選択式で正解できることと、自分で実行・説明できることを混同していないか。
- 製品によって違う操作・保存条件を一般化していないか。
- 資料は架空のものを使い、実在の顧客データを練習に要求していないか。

形式の分類には [MDNの一般的なメディア種別](https://developer.mozilla.org/ja/docs/Web/HTTP/Guides/MIME_types/Common_types)、同期の説明には [Microsoftの同期の解説](https://support.microsoft.com/ja-JP/onedrive/sync-your-computer-s-files-and-folders-with-onedrive) と [ファイルオンデマンドの解説](https://support.microsoft.com/ja-jp/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows) を参照しました。特定製品の画面操作を固定した教材ではありません。
