# インターネットの仕組み — 教材ドラフト

8レッスン・24到達項目・72問。前コースの「画面の部品」から、「接続・取得・公開・計測・運用の役割」へ進みます。

|順番|内容|目標|
|---|---|---|
|1|インターネットの言葉|接続とサービス、要求と応答の役割を分ける|
|2|URLの部品|ホスト名、パス、クエリー、フラグメントを比較する|
|3|ドメインとDNS|名前の登録と接続先の設定、キャッシュを理解する|
|4|サーバーと公開|制作・保管・ビルド・配信・実行の場所を説明する|
|5|HTTPとHTTPS|状態コード、通信保護、本人確認、権限を分ける|
|6|不具合の切り分け|症状の範囲、公開した版、保存先を確認する|
|7|アクセス計測|表示・クリック・閲覧・人数・成果の定義を揃える|
|8|運用と引き継ぎ|管理先・更新期限・復旧手順・未接続機能を記録する|

URL比較は説明用の.exampleを表示するだけで、外部サイトへアクセスしません。3つの例をキーボードでも切り替えられます。通常のHTTP要求にフラグメントを含めないことも比較できます。

実践メモには秘密鍵やパスワードを書かせません。実際の契約やネットワークの変更を必須課題にはしていません。修了課題は架空の店舗サイトの公開・運用メモで、提出・講師採点は未接続です。

正本は `course.json`、`lessons/`、`assessments/`。`demo: "url-parts"` で共通の比較部品を表示します。生成スクリプトは既存教材を上書きしません。

参考資料：[MDNのWebの仕組み](https://developer.mozilla.org/ja/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works)、[Search Consoleの表示回数とクリックの定義](https://support.google.com/webmasters/answer/7042828?hl=ja)。指標は計測対象やサービスで条件が違うため、同じ名前だけで値を比較しないことを教えます。
