# PC基礎コースの教材原稿

## 正本と確認用画面

- `course.json`：教材・問題の正本。12レッスン、36理解項目、108問。全て監修前のドラフト。
- `01-pc-components.md`：会話で検討した第1レッスンの第2稿。コース版では問題の一部をブラウザ上の選択形式へ置き換えた。
- `../../foundation-preview.html`：JSONから生成した、直接ブラウザで開ける確認用画面。
- `preview.js` / `preview.css`：確認用画面のソース。

編集は `course.json` に行い、作業フォルダのルートで次を実行する。

```powershell
node scripts/validate-foundation.cjs
node scripts/build-foundation-preview.cjs
```

`seed-foundation.cjs` は初期原稿生成の履歴。既存JSONがある場合は停止する。`refine-foundation.cjs` も初期編集の履歴で、通常の更新では再実行しない。

## 学習体験

通常は前のレッスンの確認後に次が開く。講師確認モードでは全レッスンを閲覧できる。3理解項目から各1問を出題し、不正解の項目だけ別の問題で再確認する。ヒント付きの正解でも進めるが、その履歴を区別する。

複数選択は正答集合と一致した場合に正解とし、選択肢ごとの取り違えも記録する。全て選ぶだけでは原則通過しない（問題ごとの正答集合による）。各項目3問のため、再挑戦が続くと再出題が発生する。問題を暗記できないことや理解の定着を保証するものではない。

学習メモは自己説明・講師確認の材料で、自動採点しない。12レッスンの確認完了と、コース修了の認定は別。修了課題の提出・講師採点は未実装。

## 公開とセキュリティ

現段階はローカルの教材レビュー用。GitHub Pagesの公開対象には追加していない。プレビューには正答が含まれ、ブラウザの保存内容や講師モードで進捗を変更できる。本番の受講制限や採点には使わない。

本番では正答・採点をサーバー側へ分離し、Supabaseの認証・権限・履歴保存につなぐ。既存の辞典・画像は公開対象に追加していない。

## 原稿の確認範囲

既存の用語説明を参照し、初学者向けに前提・具体例・補足を追加した。現在の機種価格やモデル名など、更新の頻繁な推奨は入れていない。全レッスンの内容は講師による確認が必要。

関係図はHTML/CSSによる簡略図で、配線図・厳密な内部構造図ではない。部品写真と専門図解は今後の教材レビューで選定する。文字数が多い項目は受講テスト後に分割する。
