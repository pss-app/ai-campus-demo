## 受講者向け解説

### 今日見るのは、いつも使っているPCです

PCは「パーソナルコンピューター」の略で、日本語では「パソコン」と呼ばれます。

画面を見たり、文字を入力したりするとき、いくつかの機器が役割を分担しています。まず、その名前と役割を確かめましょう。

今日はPCを分解したり、設定を変更したりする必要はありません。実物と図を見て、何がどの役割を持つのかを学びます。

### 1．画面と本体は、役割が違います

画面を表示する機器を「ディスプレイ」、または「モニター」と呼びます。文章や写真などを、目に見える形で表示する役割です。

「本体」には、命令に従って計算などを行う部品や、情報を保存する部品が入っています。

机に置いて使うデスクトップPCには、本体とディスプレイが別々になったものがあります。一方、本体が画面の背面などに組み込まれた一体型もあります。画面の隣に箱がなければ、本体がないという意味ではありません。

ノートPCは、本体・ディスプレイ・キーボードなどを一つにまとめた形です。まとまっていても、各部分の役割は分かれています。

【図1：本体とディスプレイが別のPC／一体型PC／ノートPCの比較。色をそろえて本体部分と表示部分を示す。実際の製品では構造が異なる旨を添える。制作予定】

### 2．入力する機器、音を出す機器もあります

| 名前 | 主な役割 |
|---|---|
| キーボード | 文字や数字を入力する |
| マウス | 画面上の位置を指し、項目を選ぶ |
| タッチパッド | ノートPCなどで、指を動かして位置を指したり選んだりする |
| ディスプレイ | 文字や画像を表示する |
| マイク | 声などの音を取り込む |
| スピーカー | 音を出す |

PCにつないで使うマウスやプリンターなどの機器を「周辺機器」と呼びます。プリンターは文字や画像を紙に印刷する機器です。

機種によって、マイクやスピーカーなどは本体に組み込まれている場合も、外付けの場合もあります。

【図2：上表の機器の写真またはイラスト。名前と役割を隣接して表示する。制作予定】

**手元で見てみよう：** 自分が文字を入力する部分と、文字が表示される部分を指してみてください。分からなければ、上の表と見比べて大丈夫です。

### 3．機器そのものを「ハードウェア」と呼びます

本体やキーボード、ディスプレイなど、物理的な機器や部品の総称が「ハードウェア」です。

本体の中に入っていて普段見えない部品も、ハードウェアに含まれます。外から触れるかどうかだけで区別するわけではありません。

### 4．機器を動かす「ソフトウェア」があります

機器だけでは、どの文章を表示するか、どんな計算をするかが決まりません。

コンピューターが行う手順や命令を記述したものを「プログラム」と呼びます。ソフトウェアは、そうしたプログラムなどをまとめて指す言葉です。

例えば、文書を書くためのアプリはソフトウェアです。「アプリ」は、文書作成など、特定の目的の作業をするためのソフトウェアを指します。

ソフトウェアには、アプリだけでなく、PC全体の動作を管理する「OS（オーエス）」もあります。OSの詳しい役割は後のレッスンで学びます。ここでは、ソフトウェアは文書作成アプリだけではない、と確認してください。

分類の練習で使う名前も、先に確認します。

| 名前 | 何を指すか |
|---|---|
| モニター | 文字や画像を表示する機器。ディスプレイとも呼ぶ |
| マウス | 位置を指したり項目を選んだりする入力機器 |
| GPU | 画像処理や大量の計算などを担う部品 |
| メモリー（RAM） | 作業中のプログラムや情報を一時的に保持する部品 |
| SSD | ファイルを保存するための部品 |
| Excel（エクセル） | 表や数式を使った作業を行うソフトウェア |
| Firefox（ファイヤーフォックス） | Webページを見るためのブラウザという種類のソフトウェア |
| Windows | OSの一つ。PCの動作を管理するソフトウェア |

各部品の詳しい仕組みは、それぞれのレッスンで学びます。ここでは名前が何を指すかを、実物写真や画面例と対応させます。

### 5．ソフトウェアで扱う情報を「データ」と呼びます

入力した文章、撮影した写真、録音した音声、計算に使う数値など、コンピューターが扱う情報を「データ」と呼びます。

文書を書く場面で区別してみましょう。

| 何を指しているか | 今回の区別 |
|---|---|
| 文字を入力するキーボード | ハードウェア |
| 文章を書くためのアプリ | ソフトウェア |
| 自分が入力した「会議は10時からです」という文章 | データ |

画面には、アプリのボタンと、自分の文章が一緒に表示されます。しかし、作業をする道具と、その道具で扱う内容は区別できます。

**「データ」と「ファイル」は、対立する分類ではありません。**

ファイルは、情報を名前の付いたまとまりとして保存・管理する単位です。例えば「売上表.xlsx」というファイルには、数値・文字・数式・書式などが保存されます。そのファイルも、保存された内容も、扱い方に応じてデータと呼びます。

まだ保存していない入力中の文章も、コンピューターが扱うデータです。保存したことで初めてデータになるわけではありません。また、同じ写真をPCからクラウドへ移しても、保存先が変わっただけでデータでなくなるわけではありません。

プログラム自体も保存や通信の際にはデータとして扱われます。そのため、ソフトウェアとデータを、どんな場面でも重ならない二つの箱として分類することはできません。

例えば、Excelというソフトウェアと、それで編集する売上表という役割を区別します。このレッスンの問題でも、何の場面で何を指しているかを明示します。ファイル形式の詳細は後のレッスンで学びます。

【図3：キーボード→文書作成アプリの画面。アプリの操作部分と入力された文章を別の色で示す。ソフトウェアとデータの両方が機器上で扱われることを示す。制作予定】

### 今日の確認

- 本体とディスプレイは、役割が違います。一つにまとまったPCもあります。
- ハードウェアは、物理的な機器や部品です。
- ソフトウェアは、機器を動かすプログラムなどです。
- 文章や写真など、扱う情報がデータです。

この区別ができると、AIから「アプリを開いて」「文章を貼り付けて」と言われたときにも、何を指しているのかを整理する足場になります。
