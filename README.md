# AI CAMPUS — 学習サイト

## 社長・関係者向けの公開デモ

https://pss-app.github.io/ai-campus-demo/

現在の5コース・44レッスン・396問を、Next.js版と同じ画面部品・教材から公開します。学習記録は各ブラウザのlocalStorageに保存されます。ログイン・決済・端末間の記録共有は未接続です。画面左の「教材確認モード」で全レッスンを閲覧できます。

公開デモはクライアント採点なので問題と正答もブラウザへ配信します。本番の試験・受講権限の保護には使用しません。サーバー版の採点APIと保存方式は維持しています。`word/` の元資料や `.local-data/` の個人記録はGitHubに含めません。

公開用ビルドは `npm run build:pages`、ローカル確認は `node scripts/serve-pages.cjs` で http://127.0.0.1:4175/ai-campus-demo/ を開きます。`node scripts/test-pages.cjs` で全コースの学習操作と全レッスンへのアクセスを検証できます。生成先 `.pages-build/` は公開専用の作業コピーです。通常のソースや学習記録を変更しません。

## 現在の実装（Next.js版）

Node.js環境で `npm install`、`npm run dev` を実行し、http://127.0.0.1:3000/ を開きます。HTMLファイルを直接開く方式ではありません。製品ビルドは `npm run build`、起動は `npm run start` です。

PC基礎12レッスン・108問、ファイルとデータ8レッスン・72問、Web・HTML8レッスン・72問、インターネット8レッスン・72問、AIの基本と言葉8レッスン・72問を学べます。合計44レッスン・396問の教材ドラフトです。各レッスンには3つの到達項目があり、項目ごとに3種類の問題を用意しています。解説と確認問題は別URLです。本文・目次・図・注意書き・問題・採点結果などは `src/components/` の共通部品です。本文は標準18px、20px・22pxへ切替可能です。

教材の正本は **`content/courses/` 内の各コースフォルダー** です。`pc-foundations/` はPC基礎、`file-data/` はファイルとデータ、`web-foundations/` はWeb・HTML、`internet-foundations/` はインターネット、`ai-foundations/` はAIの基本と言葉です。各 `course.json` はコース構成、`lessons/` はレッスンごとの解説、`assessments/` は問題・正答・補足です。今後の修正はこちらに行ってください。サーバー版では問題の正答をサーバーで採点し、回答前のAPIレスポンスには含めません。

Web・HTMLには、余白を動かして比較する練習画面と、実行せずに読むコード例があります。コードの直接入力・実行や、操作しただけでの自動合格はありません。

コース一覧は `/courses`、AI基礎コースは `/courses/ai-foundations` です。コースは好きなものから始められ、コース内では前のレッスンの理解を確認して進みます。教材確認モードでは順番を飛ばして閲覧できます。学習記録はコース別に表示・書き出しできます。最後の実践課題は案内までで、提出・講師採点は未接続です。

学習記録は匿名のブラウザ識別Cookieにひも付け、`.local-data/learning/` に保存します。再テスト・選択回答・ヒント使用・項目ごとの確認状況・学習メモを記録します。これは単一ローカルサーバー用の教材確認版です。メール認証、Supabase、Stripe、受講権限管理は未接続です。教材確認モードは認証された講師専用機能ではありません。

検証コマンド：`npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e`。ブラウザテストはインストール済みのGoogle Chromeを使います。

サーバー採点・保存を使うNext.js版の公開にはNode.jsを実行できる環境が必要です。GitHub Pagesには上記のブラウザ保存版を公開します。

## 従来のデザインモック

おすすめの閲覧方法：このフォルダで `node server.cjs` を実行して、ブラウザで http://127.0.0.1:4173/ を開いてください（Node.jsが必要です）。ルートURLでTOPが開き、フォルダ一覧は表示されません。終了は Ctrl+C です。

`index.html` をブラウザで直接開くこともできます。`file:///.../school/` はブラウザのフォルダ表示なので、サイトを見る場合は末尾の `index.html` まで指定してください。

最初にサービス紹介のTOPが表示されます。AI CAMPUSの特徴、学べること、学習の進め方、FAQから構成されています。「学習を始める」から `learning.html` に進めます。

学習画面上部のボタンで3つの学習TOPを切り替えられます。サービス紹介TOPの各コース入口からは、対応する学習TOPに直接進めます。「AI CAMPUS TOP」で紹介ページに戻れます。

- ガイド型：初心者に学ぶ順番を示す。生成AIの基礎、プロンプト、日常活用。
- 仕事別型：業務の目的から選ぶ。メール、資料、リサーチ。
- 実践型：成果物から選ぶ。企画書の構成、AIアシスタントの設計、比較リサーチ。

コースカード → カリキュラム → 解説 → 確認問題 → 次の単位の順に体験できます。正解した単位の進捗はブラウザのlocalStorageに保存されます。完了済みの単位は復習できます。

学習画面は固定教材です。実際のAI接続、ログイン、成果物の提出・採点は未実装です。実践型でもモックで確認できるのは解説と選択式の理解度チェックまでです。学習時間は企画上の目安です。

外部フォントを読み込めない場合も、端末のフォントで表示されます。

## GitHub Pagesで共有する

GitHubリポジトリにアップロード後、Settings → Pages → Source を GitHub Actions に設定します。mainへのpushまたはActionsの手動実行で公開できます。

`.github/workflows/pages.yml` はテスト後に最新版から静的ページを生成し、`.pages-build/out` を配信します。READMEやローカル用サーバーはサイトに配信しません。公開リポジトリ内のソースコードはGitHub上で閲覧できます。

GitHub Pagesは静的サイトのため、このモックの体験共有に使えます。本番用のログインや受講権限、動画へのアクセス制御は別途サーバー側の実装が必要です。
